# Critérios de aceite

## Funcional

- [ ] Home abre sem erro em `master`.
- [ ] Home abre sem erro em `analista`.
- [ ] Home abre sem erro em `cliente`.
- [ ] Cliente não vê seletor de cliente.
- [ ] Período continua persistente.
- [ ] Alterar período atualiza todos os blocos.
- [ ] Alterar cliente atualiza todos os blocos.
- [ ] Nenhum componente chama `fetch` diretamente.
- [ ] Nenhuma chamada direta ao Conta Azul.
- [ ] Build passa.
- [ ] Lint passa.

## Visual

- [ ] Inter em tudo.
- [ ] Nenhuma cor hardcoded em componente/página.
- [ ] Tema claro correto.
- [ ] Tema escuro correto.
- [ ] KPIs com `tabular-nums`.
- [ ] Espaçamentos e raios seguem tokens.
- [ ] Gráficos usam tokens corretos.
- [ ] Home não parece um relatório infinito.
- [ ] Resultado do mês tem destaque.
- [ ] Saúde financeira é visualmente importante.
- [ ] Estados vazios substituem gráficos inúteis com zero.

## Dados

- [ ] Valores atuais continuam coerentes com a Home anterior.
- [ ] Resultado = receita - despesa conforme regra existente.
- [ ] Categorias somam 100% quando aplicável.
- [ ] Top gastos ordenado corretamente.
- [ ] Insights batem com os dados.
- [ ] Nenhum insight é exibido sem suporte numérico.
